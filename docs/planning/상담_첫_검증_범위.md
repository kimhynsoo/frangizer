## 데이터 담당자가 먼저 제공할 최소 범위

첫 연결 대상으로 **소비자분쟁해결기준 본문 + 별표의 관련 범위**를 제안합니다. 전체 별표가 145쪽이므로 초기에는 대상 품목·관련 기준·조건·주석의 연결을 정확히 복원하는 데 집중합니다. 페이지 범위는 A/B가 검수 후 정하며 원본 파일은 수정하지 않습니다.

필요한 산출물은 다음과 같습니다.

1. 원문과 대조한 청크 본문. 대상 업종·품목, 표의 행·열 의미, 조건·주석 유지.
2. 현행 `IndexedChunkMetadata`에 맞는 출처·페이지·조항·섹션·판본·적용 시점·임베딩 모델·본문 해시.
3. 같은 청크에 대응하는 FAISS 인덱스와 새 `index_revision`. 검색에 사용할 임베딩 모델·차원·거리 방식 기록.
4. 조각 ID로 같은 판본의 섹션을 복원하는 방법. 본문과 메타데이터 파일의 포맷은 A/B가 합의.
5. 추출·시점 검수 결과, 알려진 누락·오류, 재현 방법. 색인 ready와 Java의 승인·배포는 별도 상태로 유지.

현행 색인 메타데이터는 엄격한 스키마이므로 임의 필드를 추가하지 않습니다. 청크 본문은 메타데이터의 임의 `text` 필드가 아닌 별도 래퍼로 합의합니다. 자세한 계약은 [데이터 담당자 인계서](데이터_파이프라인_담당자_인계서.md)와 [내부 API](../api/internal-rag.openapi.yaml)를 따릅니다.
