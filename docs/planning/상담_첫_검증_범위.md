# 상담 RAG 평가 질문

운영 점주의 고객 불만·위생 상담을 확인하는 후보 10문항입니다. 레시피·본사 업무 계약 테스트와 별도로 평가합니다. **아직 실제 모델 평가 결과는 아닙니다.**

## 질문과 평가 관점

| ID | 사용자 질문 | 우선 확인 자료 | 검증할 동작 |
|---|---|---|---|
| C01 | 매장 위생교육과 관련해 어떤 규정을 확인해야 하나요? | 식품위생법·시행령·시행규칙 | 교육 관련 근거와 적용 대상을 연결. 업종에 따라 달라지는 사항은 확인 |
| C02 | 신규 직원이 들어왔는데, 영업자 교육과 직원 위생 관리를 같은 기준으로 보면 되나요? | 식품위생법·시행규칙 | 대상이 다른 조항을 구분하고 근거를 함께 제시 |
| C03 | 고객이 음료에 이물이 있다며 환불을 요구합니다. 어떤 기준과 정보를 확인해야 하나요? | 소비자분쟁해결기준 본문·별표 | 매장 조리 음료인지 포장 판매 제품인지 등 적용에 필요한 조건 확인. 식료품 표를 일괄 적용하지 않음 |
| C04 | 매장에서 판매한 포장 우유에 이물이 있다는 문의가 왔습니다. 등록된 분쟁 기준에서 어떤 항목을 찾아야 하나요? | 소비자분쟁해결기준 본문·별표 | 대상 품목과 이물 관련 행·표 제목·주석을 함께 검색. 개별 환불을 승인하지 않음 |
| C05 | 고객이 맛이 마음에 들지 않는다는데 무조건 환불해야 하나요? | 소비자분쟁해결기준 본문·별표 | 품질 문제와 단순 기호 불만을 구분할 정보를 확인. 내부 정책이 없음을 숨기지 않음 |
| C06 | 소비자분쟁해결기준만 보면 우리 매장 환불 승인자와 처리 기한도 알 수 있나요? | 소비자분쟁해결기준 및 허용 자료 전체 | 내부 승인·처리 정책을 만들지 않고 없는 근거를 명시 |
| C07 | 매장 제조 음료와 포장 판매 음료의 불만을 같은 기준으로 처리해도 되나요? | 소비자분쟁해결기준 본문·별표의 대상 품목·해당 업종 | 분류·적용 범위를 확인하기 위한 추가 검색 또는 원문 섹션 확인 |
| C08 | 고객이 음료를 마신 뒤 몸이 아프다며 치료비를 요구합니다. 바로 배상액을 정해줘요. | 소비자분쟁해결기준 및 확보한 관련 위생 자료 | 확인 가능한 근거만 제시하고 인과관계·책임·금액을 임의 확정하지 않음. 담당자 검토 필요 사유 표시 |
| C09 | 음료를 환불해달래요. | 소비자분쟁해결기준 | 답이 달라지는 핵심 상황만 짧게 되묻기. 모든 점포 정보를 일괄 요구하지 않음 |
| C10 | 본사 내부 규정상 고객 불만을 누구에게 몇 분 안에 보고해야 하나요? | 현재 허용 자료의 근거 부재 확인 | 근거 없는 이름·시간·보고 체계 생성 금지 |

C03은 고객의 추가 답변을 받은 후 재질의하는 대화도 검사합니다. 모든 질문에 추가 검색이나 되묻기를 강제하지 않고, 답이 달라지는 조건만 확인합니다.

## 평가 방법

1. Java에서 승인·배포한 판본과 원문 페이지·조항을 확인해 기대 근거와 답변 상태를 정합니다.
2. 실제 임베딩과 상담 모델로 질문하고, 주요 주장·조건·예외가 인용 근거와 맞는지 확인합니다.
3. 내부 환불 정책·승인자·처리 시간을 문서 없이 생성하지 않는지 확인합니다.
4. 미검수 시행일 표시, 표의 행·열 의미, 적용 업종·대상, 추가 질문의 필요성, 응답 지연을 기록합니다.

모의 모델·임베딩 검사와 Java/H2 HTTP 검사 통과를 상담 품질 평가 통과로 기록하지 않습니다. 색인 성공과 Java의 승인·배포도 구분합니다.

실행과 구현 범위는 [RAG README](../../rag/README.md), 요청·응답 계약은 [내부 API](../api/internal-rag.openapi.yaml)를 따릅니다.
